# 预实验：记忆维护策略对比（时间压缩）

- 模式：真实模型 deepseek-chat @ https://api.deepseek.com/v1
- 供应商标记：deepseek-official
- 规模：40 条事实链 × 4 档延迟 × 3 种子
- 复习预算：记忆总量的 40%（绝对覆盖时用 --review-budget）；检索预算：1200 字符
- 延迟档：1, 7, 30, 90 天

## 过期误用率（越低越好）

| 策略 | 1天 | 7天 | 30天 | 90天 |
| --- | --- | --- | --- | --- |
| 不复习 | 91.7 ± 4.6% | 91.7 ± 2.3% | 91.7 ± 6.1% | 89.2 ± 4.6% |
| 最近优先 | - | - | - | - |
| 重要度优先 | - | - | - | - |
| 衰减复习（本法） | - | - | - | - |

| 策略 | 平均复习条数 | 平均归档条数 | 复习字符 |
| --- | --- | --- | --- |
| 不复习 | 0.0 | 0.0 | 0 |

## 怎么读这张表

- 四种策略的**复习预算完全相同**，差异只来自「选谁复习」，这是本实验的关键对照。
- 「衰减复习」把预算花在最久未提及的记录上，因此更容易撞见已被取代的旧记录并归档，冲突上下文变少，过期误用率应当更低。
- 若真实模型下四者差异不大，说明「复习选谁」不重要，应转向「复习时怎么写」——这本身就是一个可发表的负结果。
