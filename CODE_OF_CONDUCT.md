# Code of conduct

## Scope

This is a small research artifact. The standards below apply to issues, pull requests,
discussions and any other interaction in this repository.

## Expectations

- **Criticise the work, not the person.** This repository documents defects in its own
  study; disagreement about those findings is welcome and expected.
- **Bring evidence.** A claim about a number should include the computation. "This looks
  wrong" is a fine opening; "this is 55.4 not 47.5, here is the cell" is better.
- **Assume good faith about the original author.** The shipped package was a genuine
  attempt at reproducibility, and several of its choices were unusual for good reasons.
- **No harassment, discriminatory language, or personal attacks.** Not in issues, not in
  commit messages, not in code comments.

## Maintainer commitments

- Issues get a response within two weeks.
- A finding that contradicts something in `docs/` gets either a fix or a note explaining
  why the document stands.
- Data files are never altered in response to a dispute. If a shipped result is wrong, the
  correction goes in the documentation and a new run, not in the evidence.

## Reporting

If something in this repository makes you uncomfortable, open an issue or contact the
maintainer directly at the address in `CITATION.cff`. Reports are handled privately.

## Attribution

Adapted in spirit from the Contributor Covenant, reduced to what applies to a
single-maintainer research artifact.
